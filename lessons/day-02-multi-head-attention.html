多头注意力：Q/K/V 怎么算，位置怎么进模型

理解 Transformer，先理解注意力这一层：它用 Q、K、V 把“找什么、凭什么匹配、拿什么内容”拆成三个角色，再用分数加权混合出每个位置的新表示。多头不是把同一件事重复 h 遍，而是让不同头在不同子空间里各看一种关系；位置也不是天生就有的，RoPE 把它变成旋转角，相对距离于是直接写进点积里。

2026-11-02 · 约 18 分钟
Q/K/V 分工

Q、K、V 是三个角色，不是三个词

每个 token 进入注意力层时，会先被三个不同的线性投影分别变成 Q、K、V。Q 是当前 token 的提问：我在找什么样的信息；K 是每个候选 token 的标签：我能提供什么；V 是候选真正要交出来的内容。

三者不是词本身，而是同一向量经不同矩阵算出的三个角色。训练会调这些矩阵，让 Q 和相关的 K 更容易对上。角色分开，才有“按相关性取内容”这件事。

  • Q 只负责提问，不直接给出内容；内容在 V 里。
  • K 决定被选中的概率，V 决定被拿走的是什么。
分数怎么算

点积、缩放、softmax、掩码，四步出权重

分数是 Q 与每个 K 的点积：越对得上，分数越高。再除以根号 dk 缩放：维度高了点积天然变大，不缩放 softmax 会被推向极端，梯度变小、学习变难。

分数过 softmax 变成权重，和为 1，再按权重把各 V 加权求和。生成时还要加掩码：后面的 token 分数直接屏蔽，模型算下一个词时看不到未来。

  • 点积大只说明学到的匹配强，不等于语义上一定对。
  • 掩码是防泄漏，不是可选项；没有它，生成就偷看了答案。

为什么多头

单头一张表不够用，多头各看一种关系

单头只有一个权重分布：语法、指代、语义全挤在一张表里，容易互相平均掉。多头把 Q、K、V 各投影 h 次，每头在更小的子空间里独立算一次注意力。

各头结果拼回原维度，再经一次输出投影融合。原论文 base 模型是 8 头、每头 64 维，拼回 512 维：总计算量与单头全维接近，表达却更丰富，因为每头可以专看一种关系。

  • 头数多不等于自动分工，分工是训练学出来的，不是人工指定的。
  • 头不是越多越好：维度切太碎，每头能看到的信息就变薄。
位置从哪来

注意力本身不看顺序，顺序必须从外面给

注意力本身不看顺序：把 token 打乱重排，点积结果的集合不变，只是位置跟着变。没有位置信息，模型分不清“猫追狗”和“狗追猫”，因为它只看到一袋 token。

原始方案是给每个位置加一段正弦编码：不同频率的正弦波组合，让每个位置有唯一签名。加法简单，但位置与内容混在同一向量里，模型要自己把两者拆开。

  • 顺序必须从外面给进去，注意力层自己不会发明顺序。
  • 绝对位置签名能区分位置，但远近关系不直接体现在点积里。
RoPE

RoPE：把位置变成旋转角，距离写进点积

RoPE 不改加法，改 Q 和 K 本身：按 token 所在位置，把 Q、K 的向量对旋转一定角度。角度随位置变化，不同维度用不同频率，相当于把位置编进方向里。

关键在点积：两个被旋转过的向量做点积，结果只依赖它们的位置差，不依赖绝对位置。模型于是直接从分数里读到相对距离：近的、远的，在计算层面就有了区别。

  • 绝对位置仍在旋转角里，相对关系自然出现在点积中。
  • 旋转只改变方向、不改变向量长度，内容幅度不受位置干扰。
  • 位置差进分数不等于无限外推，长序列仍要另外验证。

后端类比与代价

像一次全表加权查询，但成本是平方级

后端类比：Q 像查询条件，K 像索引键，V 像行数据。注意力是一次对全表做的加权查询：先按键匹配打分，再按分数取行。区别是这里的键和查询都是学出来的，不是人工建的索引。

代价也要算清：每个 token 都要和前面所有 token 算一次分数，序列翻倍，分数表大约翻四倍。长上下文里注意力是平方级成本，这正是第 7 天要讲 KV Cache 与优化的动机。

  • 注意力权重高不等于模型“理解”或“引用”，只是加权混合。
  • 调试先看头与分数分布，不要只看最终输出猜原因。
  • 长序列先算平方成本，再谈窗口大小。
要点回顾

这课记住什么

  • Q 提问、K 贴标签、V 交内容，三者是同一向量的三种投影。
  • 分数 = Q 与 K 的点积，经 √dk 缩放、softmax 成权重，再加权求和 V。
  • 生成必须掩码未来，否则就是偷看答案。
  • 多头是 h 次并行注意力、拼回再融合：计算量接近单头，表达更丰富。
  • 注意力本身无顺序；RoPE 把位置变成旋转角，让位置差直接进入点积。
  • 注意力成本随序列平方增长，长上下文先算这笔账。
自测

注意力分数里，为什么要除以 √dk？

A. 让权重和恰好为 1
B. 防止高维点积过大，把 softmax 推向极端 ✓
C. 让多头维度彼此相等
D. 屏蔽生成时的未来 token
解析：维度高了，点积天然变大；不缩放，softmax 会趋向 0 或 1 的极端，梯度变小、学习变难。权重和为 1 是 softmax 本身保证的，屏蔽未来靠掩码，不是缩放。
证据

论文与文章

  • Attention Is All You Need（Ashish Vaswani, Noam Shazeer, Niki Parmar, Jakob Uszkoreit, Llion Jones, Aidan N. Gomez, Lukasz Kaiser, Illia Polosukhin，NeurIPS 2017）
    支持：多头注意力与缩放点积注意力的定义：Q、K、V 经不同线性投影、并行算注意力再拼接融合；缩放因子为 1/√dk。
    边界：原论文的主要实验是机器翻译；现代 decoder-only LLM 在掩码、规模和实现上已变化，本课只取其注意力机制定义。
  • RoFormer: Enhanced Transformer with Rotary Position Embedding（Jianlin Su, Yu Lu, Shengfeng Pan, Ahmed Murtadha, Bo Wen, Yunfeng Liu，arXiv 2021）
    支持：RoPE 用旋转矩阵编码绝对位置，同时在自注意力公式中引入显式的相对位置依赖。
    边界：原论文实验主要在长文本分类等基准上；本课只取其旋转编码机制，不直接断言所有 LLM 的长序列外推表现。
