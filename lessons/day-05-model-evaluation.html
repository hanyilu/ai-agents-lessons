模型评测方法：分数是怎么来的，又会在哪骗你

评测的本质是把“模型行不行”变成一个可以比较、可以回归的数。但任何分数都只是能力的代理：题目决定了测什么、评分规则决定了什么算对、采样方式决定了分数有多稳。看懂一张分数榜，先要问三个问题：这套题测的是不是我要的能力？测试题有没有可能被模型提前见过？这个分数的误差棒有多大？答不上来这三个问题，分数越高越危险——因为它可能只是在精确地量错东西。

2026-11-05 · 约 18 分钟
先定测什么

评测的本质：把能力压缩成一个数

评测就是给模型出一套题、按规则打分、得到一个数。数的好处是能比较、能回归：新版本上线前跑一遍，分数掉了就知道改坏了。后端类比就是压测与回归测试——没人靠感觉说系统变快了，都看指标。

但分数只是代理指标：它量的是“在这套题上按这套规则的表现”，不是“能力本身”。题目、评分规则、采样方式三者决定了分数的含义，换一套就换一个故事。指标一旦变成优化目标，就会失效，这是 Goodhart 定律。

  • 分数是代理指标，不是能力本身。
  • 三要素决定分数含义：题目、评分规则、采样方式。
  • 评测的工程价值是可比较、可回归。
Benchmark

MMLU：选择题为什么是主流测法

选择题的最大好处是评分客观、便宜、可复现：答案固定，机器就能判分，不用请人。MMLU 是 57 个学科、15908 道选择题，从小学数学到专业法律医学都有，考的是预训练阶段攒下的知识与解题能力。GPT-3 175B 首发时只有 43.9%，随机猜是 25%，领域专家约 89.8%。

但选择题测的是“认得正确答案”，不是“自己写出答案”。会选不等于会做：数学推理、写代码这类生成式能力，要用别的判法——GSM8K 看最终答案对不对，HumanEval 直接跑单元测试。选 benchmark 先问：它测的，是不是我要的能力？

  • 选择题：评分客观、便宜、可复现。
  • MMLU：57 学科、15908 题，GPT-3 175B 首发 43.9%。
  • 认得答案不等于写得出答案，生成任务要换判法。
分数的坑

平均分、抖动与饱和：分数会骗人的三种方式

第一，平均分掩盖偏科：MMLU 总分 85% 的模型，某几个科目可能只有 60%。看总分等于只看平均延迟，不看 p99。第二，分数会抖动：换一句 prompt 措辞、改一个随机种子、温度不同，分数能差几个点——小数点后一位的差距常常在噪声里。

第三，分数会饱和：顶级模型在 MMLU 上已接近 90%，大家挤在天花板附近，分数拉不开差距，就失去区分能力。MMLU-Pro 的做法是把选项从 4 个扩到 10 个、题目加难，重新把差距拉开。benchmark 也有寿命，饱和了就要换更难的。

  • 平均分掩盖偏科，要看分科分布。
  • prompt、种子、温度都会让分数抖动几个点。
  • 分数饱和后失去区分度，要换更难的题。
数据污染

数据污染：测试题混进训练集，考的是记忆

训练语料是爬全网得来的，而测试题也是公开在网上的。两者一撞，模型可能在训练时就见过原题和答案——这就是数据污染。污染后分数测的不再是能力，是记忆：模型不是推理出答案，是背出来了。

检测有三招：算 n-gram 重叠，看测试题的字串在训练语料里出现过没有；按时间切分，只用训练截止日期之后出的新题；完形填空测试，把答案挖掉看模型能不能猜中原题。缓解靠制度：保留私有测试集、动态生成新题、定期换题。看到一份分数，先问测试集的发布时间是不是晚于模型的训练截止日期。

  • 污染 = 测记忆，不测能力。
  • 检测：n-gram 重叠、时间切分、完形填空。
  • 缓解：私有测试集、动态出题、定期换题。

人工评估

人工评估：最真的标准，也最贵最慢

对开放式回答，没有标准答案可对，人才是最终标准：请人盲测、成对比较、按胜率排 Elo 分——Chatbot Arena 就是这么排的。但人工评估贵、慢，而且人之间也不总一致：同一对回答，不同的人可能选不同，GPT-4 裁判与人的一致性超过 80%，这个水平和人人之间的一致性相当。

人工评估也要讲方法：评分标准要写清、标注员要培训、同一题多人打分取多数，否则分数里混进的是标注员的个人口味。工程取舍很直白：人工评估是线上 A/B——最真，但跑不起高频；它适合做发布前的最终裁决，不适合每天跑回归。

  • 人工是开放式回答的最终标准：盲测、成对比较、Elo。
  • 贵、慢，人与人之间也不总一致。
  • 适合做发布前裁决，不适合高频回归。
LLM-as-judge

LLM-as-judge：快，但裁判自己也有偏见

请人太贵，请强模型当裁判就成了折中：让 GPT-4 这类模型给两个回答打分或排先后。Zheng 等人的实验里，GPT-4 裁判与人类偏好的一致性超过 80%，与人人一致性相当，成本却低得多。这就是它流行的原因：开放式回答终于有了可自动化的打分器。

但裁判不是中立的：位置偏见——先看到的答案占优，交换顺序结果可能翻转；啰嗦偏见——写得长的显得更好；自我偏爱——裁判给自己的输出打高分。缓解办法是成对出现：交换位置判两次取平均、控制回答长度、不用被评的模型自己当裁判。LLM-as-judge 是自动化回归：快，但系统误差要先校准。

  • GPT-4 裁判与人一致性超 80%，与人人一致性相当。
  • 三类偏差：位置、啰嗦、自我偏爱。
  • 缓解：换位重判、控长度、裁判与选手分离。

后端类比与落地

选模型的三张表，与你自己的评测集

后端类比：benchmark 是单元测试——快、便宜、窄；人工评估是线上灰度——慢、贵、真；LLM-as-judge 是自动化回归——快，但有系统误差。三张表各有盲区，合起来才可信。选模型时只看一张榜，就是只看一个指标做发布决策。

落地清单有四条：三类分数都要看，缺一类就补一类；问清测试集发布时间与训练截止日期，防污染；看分科分布不看总平均；最重要的是留一套自己的评测集——从真实业务里抽题、答案由业务方定，作为回归门禁，任何换模型、上线前都先跑它。最后注意边界：本课评的是模型本身——知识与推理能力；第 13 天的 Agent 评估评的是整个系统——成功率、成本、延迟与工具调用，两套指标别混用。

  • 三类分数合起来才可信，缺一类就补一类。
  • 问清测试集发布时间，防数据污染。
  • 留自己的业务评测集，做换模型与上线的回归门禁。
要点回顾

这课记住什么

  • 评测是把能力压缩成可比较、可回归的数；分数是代理指标，题目、评分规则、采样方式决定它的含义。
  • MMLU：57 学科、15908 道选择题，GPT-3 175B 首发 43.9%，专家约 89.8%；选择题测认得答案，不测写出答案。
  • 平均分掩盖偏科；prompt、种子、温度会让分数抖动几个点；分数饱和后失去区分度。
  • 数据污染：测试题混进训练集，测的是记忆不是能力；检测靠重叠、时间切分、完形填空，缓解靠私有题库与动态出题。
  • 人工评估最真但最贵最慢；LLM-as-judge 与人一致性超 80%，但有位置、啰嗦、自我偏爱三类偏差，要换位重判与校准。
  • 落地：三类分数都要看，留自己的业务评测集做回归门禁；模型评测与第 13 天的 Agent 系统评估是两套指标。
自测

两个模型在 MMLU 上分别是 86.2% 和 86.8%，团队据此选了后者。按本课讲的机制，这个决策最可能的问题是什么？

A. 差距太小，应直接看参数量更大的那个
B. 0.6 个点的差距很可能落在 prompt 与随机种子的抖动噪声里，应看分科分布、污染情况与自己的业务评测集 ✓
C. 选择题分数不可信，应只看人工评估
D. MMLU 已经饱和，两个模型的能力一定完全相同
解析：MMLU 这类分数会随 prompt 措辞、随机种子、温度抖动几个点，0.6 个点基本在噪声里；而且总平均掩盖偏科，公开题还可能已被污染。正确做法是看分科分布、核对测试集发布时间与训练截止日期，再用自己的业务评测集裁决。
证据

论文与文章

  • Measuring Massive Multitask Language Understanding（Dan Hendrycks 等，ICLR 2021 2020）
    支持：57 个学科、15908 道选择题的评测集；GPT-3 175B 首发 43.9%，随机猜 25%，领域专家约 89.8%。
    边界：测的是选择题上的知识与解题能力，不等于开放式对话或工具使用能力；顶级模型分数已近天花板，区分度在下降。
  • Judging LLM-as-a-Judge with MT-Bench and Chatbot Arena（Lianmin Zheng 等，NeurIPS 2023 2023）
    支持：GPT-4 裁判与人类偏好的一致性超过 80%，与人人一致性相当；揭示位置、啰嗦、自我偏爱三类偏差及缓解方法。
    边界：一致性在 MT-bench 与 Chatbot Arena 的开放式对话场景下测得；裁判能力受限于裁判模型自身的推理能力，偏差需校准后才能用。
  • Benchmark Data Contamination of Large Language Models: A Survey（Cheng Xu 等，arXiv 2024）
    支持：数据污染的定义：评测基准信息混入训练数据，导致分数虚高不可靠；系统整理检测技术与缓解策略两类工作。
    边界：这是综述，整理已有检测与缓解方法，不直接测量某个具体模型的污染率；本课的检测三招取自其整理的思路。
